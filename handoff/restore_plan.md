# ICTのねこHP 復旧計画

## 目的

ICTのねこポートフォリオを、指定された公開URL `https://ictcatfolio-ipdxgnqt.manus.space` で再び閲覧できる状態へ戻す。今回はデザイン変更やコンテンツ追加よりも、既存サイトの復旧と公開URLの再確立を優先する。

## 復旧方針

現在のプロジェクト `ict-cat-portfolio` に保存されている最新の正常なチェックポイントを基準にする。直近の確認済みバージョンは `17b8c15e` で、Apple風Liquid Glassデザイン、レスポンシブ対応、書籍・デザイン・KindEd・問い合わせ導線を含む。これを破壊的に変更せず、公開先を指定URLへ戻す。

指定URLが既存の別サイトまたは過去バージョンを指している場合は、公開処理の結果と現在の公開先を確認し、URLの再割り当てまたは同等の代替公開URLを案内する。既存データやプロジェクトファイルは削除しない。

## 実施手順

1. 現在のプロジェクトと最新チェックポイントの状態を確認する。
2. 指定URLが現在どのサイト・バージョンを指しているかを確認する。
3. 最新の正常なチェックポイントから本番公開または公開先の復旧を行う。
4. HTTPSでトップページが表示されることを確認する。
5. 書籍、Design、KindEd、Contactの主要導線と問い合わせフォームが表示されることを確認する。
6. デスクトップ幅とスマートフォン幅で大きな崩れがないことを確認する。
7. 復旧後の公開URL、使用したバージョン、未確認事項を報告する。

## 検証項目

| 項目 | 確認内容 |
|---|---|
| 公開URL | `https://ictcatfolio-ipdxgnqt.manus.space` がHTTPSで開く |
| トップページ | ICTのねこのヒーローと主要ナビゲーションが表示される |
| 外部導線 | Amazon、ココナラ、KindEd、YouTubeへのリンクが表示される |
| 問い合わせ | フォームが表示され、必須入力が機能する |
| レスポンシブ | 375px前後で横スクロールや重大な崩れがない |
| 既存コンテンツ | 最新チェックポイントの内容が欠落していない |

## 前提とリスク

この計画では、利用者が「とりあえず復旧」と指定しているため、最新の正常なサイトをそのまま公開する前提にする。過去の本屋さん型デザインなど特定の旧バージョンへ戻す必要がある場合は、別途対象チェックポイントの指定が必要になる。公開URLの管理状態や公開機能の仕様によっては、URLの再割り当てが即時にできない場合がある。その場合は、復旧可能な最新プレビューURLを先に提示し、指定URLの再設定方法を案内する。
