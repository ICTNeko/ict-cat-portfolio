# AIエージェント向け総合引き継ぎガイド（Master Handoff Guide）

このプロジェクトは、**ICTのねこ（結月汐音）**氏のポートフォリオサイトです。
他のAIエージェントが本プロジェクトを引き継ぐ際は、本ガイドおよび本フォルダ内の資料を必ず確認してください。

## 1. プロジェクトの概要
- **目的**: 著者・教育者・デザイナーとしてのポートフォリオ公開、KindEdの紹介、講座・デザイン依頼の受注。
- **構成**: React 19 + Tailwind CSS 4 (Vite) を使用した静的サイト。
- **公開先**: `https://ictcatfolio-ipdxgnqt.manus.space` (Manus WebDev環境)

## 2. デザインシステム：木漏れ日カフェ（Komorebi Editorial Cafe）
現在のデザインは「木漏れ日の漏れるカフェ」をテーマにしています。
- **背景**: 和紙やリネンの質感に、木の葉の影（Komorebi）が揺れるアニメーションを適用。
- **配色**: フォレストグリーン（#2d4a3e）、オークゴールド（#b89c6d）、生成り色（#fdfcf8）。
- **タイポグラフィ**: 日本語は「Noto Serif JP」、英数字は「Playfair Display」を主軸にしたエディトリアルスタイル。
- **演出**: スクロール追従する木製のしおりナビゲーション、手書き風付箋メモ、タップ時の触覚フィードバック、ページめくり効果音。

## 3. コンテンツの更新方法（最重要）
サイトの表示内容は、以下のファイルに集約されています。**UIコードを触る前に、まず定数ファイルを更新してください。**
- **パス**: `/home/ubuntu/ict-cat-portfolio/shared/const.ts`
- **管理データ**:
  - `BOOKS`: 自著リスト（画像、タイトル、リンク、年）
  - `COLLABORATIVE_BOOKS`: 共著リスト
  - `YOUTUBE_VIDEOS`: 動画リスト（YouTube ID）
  - `PORTFOLIO_ITEMS`: デザイン実績（画像、説明）
  - `KINDED_EVENTS`: イベント情報
  - `SERVICES`: サービスメニューと価格

## 4. フォルダ内の資料一覧
- `README_START_HERE.md`: プロジェクトの入り口と基本方針。
- `ideas.md`: 現在のデザイン詳細設計と意思決定の記録。
- `todo.md`: 完了済みタスクと今後の展望。
- `他のAIエージェントへ渡す引き継ぎプロンプト.md`: 次のAIに渡す際の推奨プロンプト。
- `ICTのねこ｜本と学びをデザインするポートフォリオ.md`: 初期の要件定義資料。

## 5. 次のAIエージェントへの指示
1. `shared/const.ts` を読み込み、現在のコンテンツを把握すること。
2. `client/src/index.css` の「Komorebi Cafe」のデザインルールを逸脱しないこと。
3. 更新後は必ず `pnpm check` で型チェックを行い、`webdev_save_checkpoint` で保存すること。
4. 本 `handoff` フォルダ内の資料も、変更に合わせて適宜更新すること。
